A modern, high-performance personal portfolio engineered with an artistic **3D Card Switching Deck** interface, glassmorphism aesthetics, responsive touch gestures, and keyboard navigation.

---

## ✨ Features

- **3D Card Switching Deck**: Sections (*About*, *Resume*, *Reviews*, *Contact*) switch with direction-aware 3D perspective transforms and physical stack underlays.
- **Dynamic Ambient Backlight**: Stage lighting smoothly shifts ambient color accents (*Electric Blue*, *Indigo*, *Purple*, *Emerald*) per active card.
- **Multi-Modal Navigation**:
  - **Deck Switcher Tabs**: Floating glassmorphic top navigation bar with dynamic active capsule slider.
  - **Keyboard Navigation**: Flip through dossier cards using <kbd>←</kbd> and <kbd>→</kbd> arrow keys.
  - **Touch & Swipe Gestures**: Smooth horizontal swipe gestures on mobile and tablet devices.
  - **Sidebar & Mobile Nav**: Synchronized navigation and browser URL hash routing.
- **Micro-Interactions**: Dynamic typed headline rotation via Typed.js, subtle canvas particle network, and responsive layout.

## 🛠️ Tech Stack

- **HTML5 & Semantic Markup**: Accessible ARIA roles, structured dossier hierarchy.
- **Modern CSS3**: 3D transforms (`perspective`, `transform-style: preserve-3d`), CSS Grid, Flexbox, custom CSS properties, glassmorphism (`backdrop-filter`).
- **Vanilla JavaScript**: Lightweight custom state machine for card transitions, touch gesture handling, and keyboard event listeners.
- **Libraries**: [Typed.js](https://mattboldt.com/demos/typed-js/) (Headline animation), [Font Awesome](https://fontawesome.com/) (Icons), [Google Fonts](https://fonts.google.com/) (*Inter* & *JetBrains Mono*).
